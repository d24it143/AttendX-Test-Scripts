
# AttendX-Test-Scripts

## Project Description
A Git and GitHub repository for managing test scripts
for the AttendX student attendance application.

## Test Scripts

### 1. login_test.py
- Tests whether login fields are provided.
- Checks detection of empty login fields.

### 2. attendance_test.py
- Checks attendance input details.
- Checks detection of a missing student ID.

## Technologies
- Python
- Git
- GitHub
- Visual Studio Code

## Purpose
To maintain test scripts, track changes, and support
collaboration among QA engineers.

- Repository maintained using Git and GitHub version control.
